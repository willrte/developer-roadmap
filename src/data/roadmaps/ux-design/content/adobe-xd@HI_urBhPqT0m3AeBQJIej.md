# Adobe XD

**Adobe XD (Experience Design)** is a UX/UI design and prototyping tool developed by Adobe, used to create wireframes, mockups, interactive prototypes, and design systems for web and mobile applications. It runs on both Mac and Windows and is known for its clean, beginner-friendly interface.

However, as of 2025, **Adobe has largely halted active development of Adobe XD**. The tool no longer receives significant updates, and much of the design community has shifted toward more up-to-date, collaborative tools.

## Key Features (Legacy)
- Intuitive interface for responsive design.
- Interactive prototyping with animations and transitions.
- Seamless integration with other Adobe Creative Cloud apps.
- ⚠️ **End-of-life status**: not recommended for new projects today.

## Recommended Alternatives
- [Figma](https://figma.com) – cloud-based, real-time collaboration, widely adopted.
- [Sketch](https://www.sketch.com) – macOS-focused, still used in some workflows.
- [Penpot](https://penpot.app) – open-source, team-friendly alternative.
